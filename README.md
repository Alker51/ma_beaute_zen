# Site Internet Ma-beaute-zen.fr

## Description
Site internet pour l'entreprise Ma beauté Zen.
Ce site permettra au client(e)s du salon de se renseigner sur les prix du salon, de créer un compte, prendre des rendez-vous et se renseigner sur les détails des rendez-vous déja pris. Ils pourront consulter aussi leurs factures ou bien contacter directement le salon.

## Installation

Cloner le projet : 

```bash
git clone https://github.com/Alker51/ma_beaute_zen.git
```

Accéder au répertoire du projet :
```bash
cd /ma_beaute_zen
```

Installer les paquets du project
```bash
composer install
```
